# 云游一中 · 枣庄一中三维校园漫游

重游校园，再见少年。走过熟悉的路，重拾那时的光。

枣庄一中三维校园漫游，内嵌四季不同音乐，支持四季昼夜与雷雨天气，可切换上帝视角和第一人称探索，还能与坤坤进行三分投篮挑战。

## 主要功能

- 全校鸟瞰、建筑标注、多个观察视角和截图保存。
- 春夏秋冬树木、秋季落叶、冬季积雪、飘雪与装饰雪人；雪花大小和密度可调。
- 昼夜切换、雷雨、雨声和远雷、湿润地面与通道照明。
- 四季固定音乐循环播放，支持暂停及音量调节。
- 第一人称步行、骑行、坐下与躺下。
- 篮球场坤坤以及跑步、散步、羽毛球、足球、草坪打牌和野餐人物。
- 第一人称五轮三分挑战：按住空格蓄力，松开出手；拖动场景调整方向和仰角。

## Windows 直接运行

在仓库右侧 **Releases** 点击`云游一中v1.0.0`，进入后下载 `YunYouYiZhong.zip`，完整解压到一个新文件夹，运行 `重游校园.exe`。请保留同文件夹下的 resources、locales、DLL 等运行文件。

## 从源码预览

安装 Node.js 后，在仓库根目录运行：

```sh
npm start
```

浏览器打开 <http://127.0.0.1:4186/>。网页库保存在 `site/vendor`，无需外部 CDN；本地预览服务仅监听本机地址。

如需桌面窗口：

```sh
npm install
npm run desktop
```

## 操作

| 模式 | 操作 |
| --- | --- |
| 鸟瞰 | 左键旋转、滚轮缩放、右键平移 |
| 第一人称 | WASD / 方向键行走、Shift 快走、鼠标环顾、Esc 菜单 |
| 休息 | C 坐下或站起；Z 躺下或起身，休息时不能移动 |
| 自行车 | 靠近校门出生点的自行车，F 上车或下车 |
| 投篮挑战 | 走近坤坤按 E，或点击侧栏挑战按钮；拖动瞄准，空格蓄力后松开 |

首次在普通浏览器中播放音乐可能需要点击“播放音乐”。

## 项目结构

- `site/`：网页、校园建模、交互、人物和天气代码。
- `site/vendor/`：Three.js 0.180.0 及 OrbitControls。
- `site/audio/`：用于四季循环的压缩音频。
- `desktop/main.cjs`：Electron 桌面启动入口。
- `scripts/package-windows.cjs`：在 Windows 上组装便携目录。

在 Windows 64 位环境安装依赖后，运行 `npm run build:windows`，输出目录为 `dist/重游校园-Windows-x64`。此步骤组装目录，不生成安装器。
